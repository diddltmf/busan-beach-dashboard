부산 주요 해수욕장 연도별 방문객 수 변화 대시보드

부산의 주요 해수욕장(해운대, 광안리, 송정, 다대포, 송도)의 최근 5년간(2019~2023년) 방문객 수 추이를 한눈에 확인할 수 있는 Streamlit 기반 웹 대시보드 프로젝트입니다.

📌 주요 기능

📊 방문객 수 데이터 표 제공: 연도별·해수욕장별 방문객 수(단위: 만 명)를 깔끔한 표 형태로 확인할 수 있습니다.

📝 핵심 분석 요약: 팬데믹 기간의 방문객 감소와 이후의 회복 추세 등 주요 인사이트를 요약해 제공합니다.

📈 연도별 추이 라인 차트: 각 해수욕장의 방문객 변화 흐름을 인터랙티브 선 그래프로 시각화합니다.

🛠️ 사용 기술 (Tech Stack)

Language: Python

Web Framework: Streamlit

Data Processing: Pandas
